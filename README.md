# MOROCCAN TRAVERTINE

Next.js site for a design-forward handmade Moroccan furniture brand (SEO + content plan per client brief).

**Repository:** [github.com/HAMZAamejoudj/ATELIER-ATLAS](https://github.com/HAMZAamejoudj/ATELIER-ATLAS)

## Stack

Next.js 16 · TypeScript · Tailwind CSS v4 · shadcn/ui · MDX blog · JSON-LD (schema-dts) · next-sitemap · Resend (contact) · next-intl (FR later)

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build + sitemap |
| `npm run start` | Run production build |
| `npm run lint` | ESLint |
